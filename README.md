# SPI-Bus-Protocol-with-Built-In-Self-Test-BIST-
A Verilog implementation of the SPI (Serial Peripheral Interface) protocol with an integrated Built-In Self-Test (BIST) module. The project features synthesizable SPI Master/Slave designs, automatic self-testing, and simulation testbenches, making it ideal for FPGA, ASIC, and VLSI learning.
